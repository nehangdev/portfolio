Live chart sandbox

This page has no Angular app and no build step. It loads one script and uses <nehang-live-chart> like any other HTML element. The colours, font and toolbar tint come from this page's own CSS.

Pause or resume the chart to see its pausechange event here.

The markup

<script type="module" src="/elements/live-chart.js"></script>

<nehang-live-chart window-seconds="30" label="Sandbox series" seed="3"></nehang-live-chart>

<script>
  document.querySelector('nehang-live-chart')
    .addEventListener('pausechange', (e) => console.log('paused:', e.detail));
</script>
